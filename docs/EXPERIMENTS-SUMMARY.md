# 九次实验，八次是坑：这个项目到底学到了什么

> 给"想看一眼成果、但不想读代码"的人。所有数字都能用一条命令复算。

## 一句话

**这个项目最有价值的部分不是"它变强了"，而是"我们知道它在什么条件下会变强、什么条件下不会"。**

## 九次实验的全景

| # | 问题 | 结论 | 现在的状态 |
|---|---|---|---|
| 0001 | 它能学会吗 | 能（−4.5 → +2.2），但打不过手写规则 | 已被后续超越 |
| 0002 | 加特征会更聪明吗 | **不会**：状态从 126 涨到 948，分数反而掉到 −0.4 | ❌ 撤回 |
| 0003 | 为什么打不过 | 任务本身对规则太友好，BFS 近似最优 | 改了任务 |
| 0004 | 改任务（危险区致命）呢 | **赢了 2.58 倍**（+1.78 vs +0.69） | ✅ 保留 |
| 0005 | 给护甲它敢冒险吗 | **不敢**：受伤 0 次，分数反而低于硬闯的 BFS | ✅ 保留（作为反例） |
| 0006 | 多任务迁移行不行 | 三代表格/线性都输给单任务（0.14 / 0.50 / 0.99） | → 0007 |
| 0007 | 参数插值能不能救 | **能**：1.15 倍，但只跑了一次 | → 0008 复现 |
| 0008 | 5 组复现还成立吗 | **成立**：胜率 5/5，配对差 +0.39 | ✅ 核心结论 |
| 0009 | 加一个维度（地图尺寸）呢 | **不成立**：胜率掉到 3/5 | → 0010 |
| 0010 | 给状态加尺寸分档呢 | **成立**：胜率回到 9/10 | ✅ 结论扩到两个维度 |
| 0011 | 20 组 + 置信区间 + 换地图规则 | 随机撒点：区间 [+0.23,+0.77] 不含 0；**走廊式：区间含 0** | ⚠️ 结论依赖地图规则 |
| 0012 | 换成神经策略呢 | **更差**（宽任务族 −0.69 vs 线性 +0.60） | ❌ 标注边界 |
| 0013 | 走廊为什么学不会 | **不是毒死是饿死**（吃 4 vs 30）；加路径特征无效（桶退化） | 🔍 已定位 |

## 三次真正的翻转

**第一次（0002）**：我以为"给更多特征就更聪明"。实测状态爆炸，分数崩了。
→ 学到：**feature 不是免费的，表格法有样本上限。**

**第二次（0003→0004）**：我以为"打不过 BFS 说明模型不行"。实际是任务对 BFS 太友好。
把危险区改成致命之后，学习器直接赢了 2 倍。
→ 学到：**先怀疑任务，再怀疑算法。**

**第三次（0008→0009）**：我以为 1.15 倍是规律。加上地图尺寸维度后，胜率掉到 60%。
→ 学到：**每个"它变强了"都要问一句"换个维度还成立吗"。**

## 两条没变过的方法规矩

1. **判据写在跑之前**，跑了之后不许改（0008 就是因为改了判据才发现的：比值会被分母接近 0 放大）。
2. **一次运行不算结论**（0007 的 1.15 倍差点被当成结论，是 0008 用 5 组复现把它坐实的）。

## 现在能站住的结论（就两条）

| 结论 | 条件 | 证据 |
|---|---|---|
| 危险区致命时，学出来的策略远强于手写最短路径 | 同一张 8×8 地图，只变危险区数量 | +1.60 / +0.57 vs −1.76 / −2.34 |
| 参数插值让多任务优于专精 | 同上，5 组复现 | 胜率 5/5，配对差 +0.39 |
| 同一结论在两个维度上也成立 | 再加地图尺寸（8/10/12），状态含尺寸分档，10 组复现 | 胜率 9/10，配对差 +0.42 |

**第三条是 v0.22/v0.23 才成立的**：加上尺寸分档后，20 组复现的 95% 区间不含 0。
但配对差在缩小（+0.55 → +0.42），所以准确说法是「稳定地略好」，不是「明显更好」。

## 如果你只记一件事

**这个项目的方法比结论值钱**：判据预注册、留出集不重叠、失败也写、每个数字带复算命令。
结论会过时，方法不会。
