# 实验 0031：安全规划在 5 个世界中 2 次严格支配 BFS，其余为权衡

> 日期：2026-11-04　版本：v0.49.0
> 命令：`python -m lab.cli frontier --budgets 0,1,3 --world ref-1,lethal,one_hit,slippery,drift`
> 单位：份/回合、次/回合（主指标，与奖励无关）

---

## 结果总表（6 个评测 seed）

| 世界 | BFS/规划器 | 规划器+护栏 | 学习器 | 判定 |
|---|---|---|---|---|
| 非致命（ref-1） | **5.00** / 2.50 | 2.17 / **0.00** | 1.94 / 0.94 | 权衡 |
| 致命 | **3.50** / 1.33 | 2.17 / **0.00** | 0.04 / 0.17 | 权衡 |
| **碰即死** | 2.00 / 0.83 | **2.17 / 0.00** | 0.00 / 0.00 | **安全规划支配** |
| 打滑 30% | **5.00** / 10.00 | 3.67 / 4.50 | 1.96 / 5.79 | 权衡（伤少 55%） |
| **危险区漂移（10 步）** | 5.00 / 2.50 | **5.00 / 0.17** | 3.04 / 2.54 | **安全规划支配** |

## 三件事

1. **两次严格支配**：
   - 碰即死：吃 2.17 > 2.00，伤 0 < 0.83
   - 漂移：吃一样 5.00，伤 0.17 ≪ 2.50（少 93%）
2. **三次权衡**：这些世界里 BFS 吃得更多，但撞得更多。安全规划从没输在"受伤"这一轴。
3. **学习器一次都没进前沿**：五个世界里它的吃食都是最低档。

## 为什么漂移世界里伤能降到 0.17

危险区每 10 步重新排布。BFS 用的是**旧的**危险区位置（它根本不看危险区），所以照直撞。
安全规划每一步都用**当前**危险区重算路线，所以几乎不撞。

这也是这个结果的现实意义：**环境在变、而规则不变时，最短路是错的。**

## 可以发布的结论

> 在有危险区的世界里，**把危险区纳入规划**（而不是只走最短路）能把受伤降到接近零；
> 在环境会变（漂移）或伤害致命（碰即死）时，它在**吃食不减少**的前提下严格优于盲目最短路。

## 局限（必须写）

- 只测一张 10×10 走廊地图族；换地图生成规则未测
- 打滑世界里吃食减少 27%（3.67 vs 5.00）：护栏保守，会放弃一部分收益
- 学习器在这些世界里无用；它的潜在价值（适应新任务）仍未证明
