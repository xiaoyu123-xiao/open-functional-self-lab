# 实验 0012：换成神经策略之后，反而变差了

> 日期：2026-11-04　版本：v0.24.0
> 复算：`python -m lab.cli transfer --algo neural --family wide --repeats 5`
> 　　　`python -m lab.cli transfer --algo neural --family corridor --repeats 5`

---

## 动机

走廊地图上线性策略卡在负分（−0.39），我判断是**表达能力**不够：
"如果左边是墙且食物在右，就先向下"这种条件，线性权重表达不了。

于是写了纯 Python 的单隐层 MLP（25→16→5，tanh，手写反向传播）：
`lab/neural.py`，`--algo neural`。

## 第一件事：学习率错了会直接发散

| 学习率 | 训练前 → 逐轮 |
|---|---|
| **0.002** | −0.025 → 0.675 / 1.337 / 1.337 / 1.400 / 1.337　**稳定** |
| 0.005 | −0.025 → 1.312 / 1.675 / 1.438 / 1.450 / 0.988　先好后抖 |
| 0.01 | −0.025 → 1.375 / 1.125 / 1.550 / 1.163 / **−1.675**　发散 |
| 0.02（初版） | −0.025 → **−0.512**　直接学坏 |

默认改成 0.002。**这是我这轮唯一"调"的东西**，而且调完就把四个值都贴出来。

## 第二件事：宽任务族上，神经明显不如线性

| 策略 | 单任务均分 | 多任务均分 | 配对差 | 95% 区间 |
|---|---|---|---|---|
| **线性加权（v0.22）** | +0.413 | **+0.599** | +0.186 | — |
| **神经（本次）** | −0.726 | **−0.686** | +0.040 | [−0.124, +0.204] |

神经版在 `12×12` 上甚至是 **−0.31**，而线性版是 **+1.06**。

## 第三件事：走廊地图上，神经也没救回来

| 策略 | 单任务 | 多任务 | 配对差 | 区间含 0 |
|---|---|---|---|---|
| 线性（v0.23） | −0.391 | −0.266 | +0.125 | 是 |
| **神经** | −0.790 | −0.811 | −0.021 | 是 |

两个都是负分，多任务还略差一点。**换函数逼近没有解决走廊问题。**

## 结论（三条）

1. **表达能力不是万能钥匙。** 在这个样本量（每配置 120 回合 × 60 步）下，16 个隐单元的网络
   参数比线性多一个数量级，反而不如线性稳。这是典型的"小数据 + 大模型"。
2. **走廊任务的问题不在策略族，在任务本身**：60 步、整行墙、只留两端缺口，
   连 BFS 都只有 −0.25 到 −4.06。**先改任务，再换模型**——这是实验 0003 的教训第二次应验。
3. **判据 v3 又一次拦住了一个假结论**：神经版在宽任务族上胜率 80%，但区间含 0。
   如果只看胜率，就会写成"神经策略也支持迁移"。

## 那神经策略还有用吗

有，但不在这个任务上：

| 场景 | 适用 |
|---|---|
| 需要条件判断的连续控制 | ✅（有足够样本时） |
| 小样本、离散动作、表格化观测 | ❌ 线性更稳 |
| 需要 GPU 的大规模训练 | ✅（但那时该用 torch，不是这份纯 Python 实现） |

## 下一步

1. **先修走廊任务**：把 60 步放宽到 120、把整行墙改成稀疏隔断，看能否让 BFS 与策略都转正
2. 任务正常化之后，再用同一判据比较神经 vs 线性
3. 若那时神经仍不如线性，就写"本任务族上线性足够"，不再追新模型
