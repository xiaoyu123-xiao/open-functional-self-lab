# 实验 0005：给了护甲，它反而不敢用

> 日期：2026-11-04　版本：v0.8.0
> 复算：`python -m lab.cli eval --lethal --armor`

---

## 为什么要加护甲

你问了一句很关键的话："**怎么会怕死呢？**"

我当时的设计里，危险区致命（两次即死），所以"躲开"是唯一活路。为了让它有第二条路，
v0.8 加了**护甲**：中毒先扣甲（0.4/次），甲没破就不受伤，不受伤时每步回 0.01。
于是策略空间变成：**躲** 还是 **扛过去换更快路线**。

## 结果：它选了"绝对不受伤"

| 方法 | 分数 | 吃到 | 受伤 |
|---|---|---|---|
| BFS（没甲） | 0.691 | 79 | 22 |
| **BFS（有甲，硬闯）** | **4.765** | 100 | 22 |
| 学习器（有甲） | 3.345 | 75 | **0** |

**BFS 靠甲硬闯得了 4.765，学习器只拿 3.345，而且受伤 0 次。**

也就是说：给它甲之后，它**变得更保守了**——一次都不肯受伤，因此也永远吃不到"扛一口毒换一条近路"的红利。

## 为什么（这是本次实验真正的发现）

不是它"胆小"，是**我给的价目表让它胆小**：

| 事件 | 我给的奖励 |
|---|---|
| 吃到食物 | +1 |
| 受伤 | **−1** |
| 死亡 | **−5** |
| 每步 | −0.01 |
| 靠近食物 | +0.1 × 距离减少 |

在"受伤 −1、死亡 −5"的定价下，**"永不受伤"是数学上的最优解**——因为甲的收益（省一步）远小于一次受伤的代价（−1）。
它学会的不是"怕死"，是"我做的那道题的最优解就是别受伤"。

**要让它敢冒险，得改价目表，不是改它。** 这不是调参作弊——这是承认奖励设计决定了行为，
而且必须把这件事写在明面上，否则下一个人会以为是"模型太保守"。

## 这同时给出了"涌现"的一个操作性定义

`python -m lab.cli emergent` 会把账本里的行为切成前后两半对比：

```
行为特征（前一半记录 → 后一半记录）：
  hazard_entry_rate       0.051 →    0.034
  rest_ratio              0.034 →    0.170
  food_camp_ratio         0.271 →    0.119
  action_entropy          2.767 →    2.179
```

判据是：**某个行为变化超过阈值，且没有人直接奖励过它**。例如 `rest_ratio` 从 3% 涨到 17%、
`food_camp` 从 27% 降到 12% —— 这些都不是奖励项，是训练后行为分布自己长出来的。

**它仍然不叫"意识"**：它只说明"行为分布变了"。但这个定义是可以被别人复算、被反驳的，
比"看起来有灵性"强。
