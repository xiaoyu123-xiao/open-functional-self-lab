# 实验 0009：把任务族放宽之后，迁移不成立了

> 日期：2026-11-04　版本：v0.21.0
> 复算：`python -m lab.cli transfer --algo weighted --family wide --repeats 5`

---

## 目的

v0.16 的结论是"多任务在没见过的配置上胜率 100%"，但那个任务族**只变了一个维度**（危险区数量），
地图尺寸固定 8×8。这次加第二个维度：**地图尺寸**（8/10/12）。

## 配置

| 用途 | 配置 |
|---|---|
| 训练 | (8×8, hazards=4, 致命)、(10×10, hazards=6, 致命)、(8×8, hazards=4, 非致命) |
| **留出** | **(12×12, hazards=6, 致命)、(10×10, hazards=10, 致命)** ← 训练从未出现 |
| 重复 | 5 组不同初始种子 |

## 结果

| 指标 | core 任务族（v0.16） | **wide 任务族（本次）** |
|---|---|---|
| 单任务留出均分 | +0.590 | +0.413（±0.556） |
| 多任务留出均分 | +0.980 | +0.962（±0.419） |
| 配对差 | +0.390 | +0.549（±0.691） |
| **配对胜率** | **100%（5/5）** | **60%（3/5）** |
| 判据（≥80%） | ✅ 成立 | ❌ **不成立** |

逐配置（留出）：

```
12×12 hazards=6  致命：BFS +1.528　多任务 +0.932   ← BFS 又赢了
10×10 hazards=10 致命：BFS −1.460　多任务 +0.367
```

## 结论

1. **"加权插值让多任务优于单任务"只在窄任务族上成立。** 加上尺寸维度后胜率掉到 60%。
2. **大图上手写规则重新占优**：12×12 有更多绕行空间，BFS 不需要穿毒区就能吃到食物，
   它的结构性盲点被地形稀释了。
3. 方差变大（±0.691），说明这个结论本身不稳定。

## 这对项目意味着什么

之前 v0.15/v0.16 的"成功"被更宽的任务族**部分推翻**了。这不是坏事，
但它说明：**每次想宣称"它变强了"，都必须先问"换一个维度还成立吗"。**

已写进 `docs/self-audit.md` 的"叙事偏好"一节：我容易把一次成功写成规律。
