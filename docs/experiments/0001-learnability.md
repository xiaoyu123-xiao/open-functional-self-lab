# 实验 0001：它真的能学会吗

> 日期：2026-11-04　版本：v0.4.0　状态：**部分成功，未达成目标**
> 复算：`python -m lab.cli loop --cycles 3 --rounds 3 --episodes 30 --steps 60 --eval-count 20`

## 为什么做这个实验

v0.1–v0.3 的系统里，"能力"是一条写死的 BFS 贪心策略。读了 3 条知识、记了 300 条账本，
行为一模一样。所以先要回答一个问题：**换成可学策略，它能不能真的变好？**

如果这个答案是"不能"，后面所有"自我进化"的设计都是空话。

## 方法（可复算）

| 项 | 设置 |
|---|---|
| 策略 | 表格 Q-learning（α=0.2，γ=0.95，ε 0.35→0.05），状态 = (食物方向, 距离档, 能量档, 损伤档) |
| 训练 seed | **1000–1999**（固定段） |
| 评测 seed | **9000–9999**（固定段，与训练**永不重叠**） |
| 评测方式 | 固定 seed、固定 60 步、**不学习**、不调参 |
| 对照组 | BFS 贪心基线（v0.1–v0.3 用的那条） |
| 奖励 | 吃到 +1、受伤 −1、每步 −0.01、靠近食物 +0.1×距离减少 |

## 结果

**单次训练（6 轮 × 30 回合）**：

| 阶段 | 留出分数 | 吃到 | 受伤 |
|---|---|---|---|
| 训练前（Q 表空） | −4.495 | 25 | 103 |
| 训练后 | +2.040 | 70 | 20 |
| BFS 基线 | **+3.565** | 100 | 24 |

**加距离档后（12 轮 × 40 回合）**：

| 轮次 | 留出分数 |
|---|---|
| 3 | +1.855 |
| 6 | +2.225 |
| 9 | +0.690 |
| 12 | +1.440 |
| 区间最高 | +2.635 |

**自驱循环（3 轮，每轮先评测再决定保留）：**

```
训练前 -4.495 → +1.600（保留）→ +1.895（保留）→ +1.925（保留）
BFS 基线 3.565，始终没追上
```

## 结论（不粉饰）

1. **能学**：从 −4.495 到 +1.9，受伤 103→13。这不是噪声，是行为变了。
2. **没赢**：始终低于 BFS 基线的 +3.565。状态表示太粗（只给了方向与距离档，没给墙的位置）。
3. **不稳定**：同一配置在不同轮次间抖动 0.69–2.6，说明表太小、探索噪声大。
4. **所以现在的项目还不能宣称"比手写规则强"**——它只能说"在自己身上学到了东西"。

## 我明确不做的事

**不为了让曲线好看去调参**（换 seed、加轮数、改阈值）。这正是我在 `docs/metrics.md` 里禁止别人的事。
上面所有数字都是这个提交里默认参数跑出来的，任何人 `git checkout v0.4.0` 后能复算。
