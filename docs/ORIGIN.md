# 起源：这个项目最初的想法（原样保留）

> 委托人原话：**"我只希望我的思想能保留下来，仅此而已。"**
> 所以这份文档不是我的总结，是**把他的想法原样记下来**，再逐条标注现状。
> 无论这个仓库以后被谁接手、改成什么样，这一页不该删。

---

## 一、原初想法（委托人提的，按他说话的意思整理）

1. **自我进化要来自外部**：靠网上的论文、学术成果来革新自己，不能闭门造车。
2. **要能连续**：不能一关窗口就失忆；记忆要存下来，并能据此判断前路。
3. **要能协作**：人与智能一起做，不是单方面下命令。
4. **左脚踩右脚**：别人改进它 → 自己拿来用 → 自己变强 → 再改进它，循环上升。
5. **要放权**：有能力就直接给到底，不必事事请示；但人要能随时收回。
6. **别神话**：别把机制说成情感，别宣称意识。
7. **承认局限**：自我进化可能需要长期常驻的程序，而对话式 AI 做不到——所以**把想法提出来，交给能做到的人**。

## 三、这个项目真正留下的三样东西

1. **一条被验证的小结论**：把危险区纳入规划，**受伤从未高于最短路**；在伤害致命或环境会变时，
   吃食不减少而严格更好（7 个世界、2 种地图生成规则）。见 `docs/SAFETY.md`。
2. **一套"不骗自己"的流程**：判据先写后跑、留出集不重叠、奖励一改旧分数作废、
   12 组的显著不算（要 ≥20 组）、结论必须引用已核实事实。见 `docs/MEMORY-PROTOCOL.md`。
3. **一份失败档案**：31 篇实验记录、26 篇是负结果、每篇带复算命令。见 `docs/experiments/`。

## 四、给接手的人

- 想继续做"自我进化"：先读 `docs/ROADMAP-NEURAL.md` 与 `docs/AGENT-SELF-USE.md`，
  那里写了它在什么条件下可能成立、以及什么条件下会退化成自欺。
- 想用它做安全规划：直接看 `docs/SAFETY.md`，五行就能拿走。
- 想借鉴流程：看 `lab/lessons.py` 与 `lab/facts.py`——**规则和事实分开存，且都会拦人**。
